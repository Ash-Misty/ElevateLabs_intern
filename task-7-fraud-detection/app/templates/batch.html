API access

Prefer to script it? The same scorer is exposed as JSON.

Score one transaction

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"Time": 2600, "V14": -1.9, "Amount": 1850, "V1": 0, ...}'

Score a batch

curl -X POST http://127.0.0.1:5000/api/batch \
  -H "Content-Type: application/json" \
  -d '{"transactions": [{...}, {...}]}'

All 30 features are required; a request missing any of them returns HTTP 400 with the missing list.
